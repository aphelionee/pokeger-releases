# Pokeger — журнал выпусков

Здесь записан каждый выпуск Pokeger, когда-либо опубликованный: версия, имя
файла, размер и SHA-512. Установленный Pokeger ставит обновление, только если
оно записано здесь и не отозвано. История этого репозитория — открытая запись
каждого изменения: выпуск «для нескольких» сначала увидели бы все.

# Pokeger — the release journal

Every Pokeger release ever published: version, file name, size and SHA-512.
An installed Pokeger takes an update only when it stands here and is not
revoked. This repository's history is the open record of every change.
